# Press Release Template — Author Guidance

Calibrates `asset.md` for `press-release` to the company's distribution platform and PR conventions.

## When this template is generated

- `/bootstrap` Phase 8 with "press-release" selected.
- `/design asset press-release` directly.

## What makes a good format spec

- **Wire format discipline.** AP style by default. List exceptions explicitly.
- **Approved quotes.** Press releases carry quotes attributed to named individuals. Format should enforce approval.
- **Boilerplate from pillar.** The closing boilerplate must pull from `messaging/pillars/profile.md` — never paraphrased per release.

## Common pitfalls

- Marketing superlatives in the lede. Press editors strip them; format should ban them.
- Marketing CTAs. Press releases have media contact info, not "Schedule a demo."
- Forgetting distribution-platform requirements. Wire services have rigid fields; format should capture them.
